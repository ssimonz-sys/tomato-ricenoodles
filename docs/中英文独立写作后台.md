# Tomato Ricenoodles 中英文独立写作后台

## 正式入口

| 功能 | 中文站 | English edition |
| --- | --- | --- |
| 写作 | `/admin/zh/` | `/admin/en/` |
| 作品管理 | `/admin/zh/manage/` | `/admin/en/manage/` |
| 对外网站 | `/zh/` | `/en/` |

`/admin/` 和 `/admin/manage/` 现在是站点选择入口。之前收藏的深层链接（例如 `?id=…` 或 `?book=…`）保留兼容，无法从地址判断语言时进入 `/admin/legacy/` 及 `/admin/legacy/manage/`。这些旧版页面不建议用于日常写作。

## 使用和存储原则

- 只有一套 Cloudflare Pages Functions 后端和 D1 数据库，沿用已配置的管理员密码与会话；**无需迁移或清空数据**。
- 两个新版后台的 `window.TRNAdminSite.lang` 是固定的：中文 `zh`、英文 `en`。不再让编辑人员在本页随意切换文章语言。
- 写作页面的文章列表只载入当前站点的文章；输入另一站点的文章编号会跳转到对应写作页面。
- 管理页面的系列、书籍、章节、文章列表和待审核评论，均按当前站点筛选。
- 书籍仍是可点击的卡片；点击书籍进入详情后查看和编辑章节。点击「写新章」直接进入该语言的写作编辑器。
- 同一套文本编辑器、专注模式、封面图片上传和 D1 存储供两个后台使用。
- 英文后台的静态文案和常用动态控件显示英语；作品标题、内容和用户输入不做自动翻译。

## 开发维护

- 后台页面：`admin/{zh,en}/index.html` 和 `admin/{zh,en}/manage/index.html`
- 后台站点状态由页面头部的 `window.TRNAdminSite` 指定。
- 共用 JS：`assets/admin.js`、`assets/manager.js`、`assets/editor-placement.js`、`assets/writing-studio.js`
- 独立英文显示翻译：`assets/admin-edition-i18n.js`。不修改数据库里的作品内容。
- 统一后台入口：`admin/index.html` 和 `admin/manage/index.html`
- 旧版备份入口：`admin/legacy/` 和 `admin/legacy/manage/`
- 静态资源带发布版本参数，减少浏览器使用旧脚本的概率。
