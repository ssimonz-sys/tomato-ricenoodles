# 番茄米线：封面图片上传（免费 D1 版）

**完全不需要开通 Cloudflare R2，也不需要绑定银行卡。**

网站沿用原有 Cloudflare Pages + D1 数据库 `trn-writings`，封面图片作为 BLOB 存在一个新表 `trn_cover_images` 中。第一次上传时，后台自动执行 `CREATE TABLE IF NOT EXISTS`，现有文章、系列、书籍、草稿和统计表都不会被修改。无需你去 Console 手动复制 SQL。也保留了 `migrations/2026-11-10-d1-covers.sql` 供手动升级备用。

## 直接使用

1. 等 Cloudflare Pages 自动部署 GitHub `main` 最新代码。
2. 登录 `https://tomatoricenoodles.pages.dev/admin/`，在作品设置中选择文章封面；或在 `/admin/manage/` 中编辑系列封面、书籍封面。
3. 点击「从电脑上传封面」或拖拽 JPG、PNG、WebP、GIF。
4. 上传成功后会自动填好相对网址 `/media/covers/<uuid>.<ext>`。
5. 文章草稿通过原有自动保存逻辑写入封面地址，公开文章需点击保存；系列和书籍需点击编辑弹窗「保存」来正式使用新封面。

## 封面大小

D1 官方限制一条 BLOB 或行最多约 2 MB；这里把实际存储上限设为 **1.2 MB**。原始 JPG/PNG/WebP 可先选取最多 **5 MB** 的文件，浏览器会自动降低分辨率并尝试转换为 WebP，再上传。GIF 可以保留动画，但需小于 1.2 MB，较大的 GIF 请先在本机压缩。

Cloudflare Free D1 存储限制为单个数据库 **500 MB**，账户总免费存储 **5 GB**，因此这套方案适合个人文学网站的封面，不适合海量原图存档。注意：封面图片占用同一个 D1 的空间，请定期查看数据库用量。

## 安全和兼容

- 只有管理员会话且通过 CSRF 验证后能上传图片；普通访客仅可读取公开图片。
- 服务端通过文件头检测图片类型，拒绝 SVG 以及伪装为图片的文本文件，上传文件名改为随机 UUID。
- 图片以正确的 MIME 和 `X-Content-Type-Options: nosniff` 返回；永久缓存由唯一文件名保证。
- 已有的 HTTPS 图片和本地 `/assets/graphics/` 封面依然可用。
- 换掉封面并不会自动删除旧 D1 图片，以免误删共享资源；需要清理功能时再增加图库管理。
- 整个项目无需新建 Cloudflare 绑定，也无需更改 `ADMIN_PASSWORD`。继续使用已经配置好的 D1 绑定变量 `DB` 即可。

核心文件：

- `functions/api/admin/upload-cover.js`：登录校验、上传 D1 BLOB、自动创建图片表
- `functions/media/covers/[file].js`：公开图片读取
- `assets/cover-upload.js`：选图、拖放、客户端缩小压缩和上传进度
- `migrations/2026-11-10-d1-covers.sql`：可选手工迁移
