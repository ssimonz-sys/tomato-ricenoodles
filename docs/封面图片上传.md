# 番茄米线：从电脑上传封面

新增的上传按钮出现在：

- `/admin/` → 作品设置 → 文章封面；
- `/admin/manage/` → 新建/编辑系列 → 系列封面；
- `/admin/manage/` → 新建/编辑书籍 → 书籍封面。

支持点击「从电脑上传封面」、拖拽文件、预览，也保留原来的图片网址输入。上传时直接把图片存入专属 Cloudflare R2，文章、书籍、系列表中只记录图片的相对 URL。现有数据库**不需要迁移**。

## 只需一次：在 Cloudflare 创建 R2

1. 打开 Cloudflare Dashboard → Storage & databases → R2 Object Storage → Create bucket。
2. 新建一个存储桶，**Bucket name: `trn-covers`**，地区按默认即可。
3. 进入 Workers & Pages → 选中 Pages 项目 **`tomatoricenoodles`**。
4. 进入 Settings → Bindings → Add → **R2 bucket**。
5. Variable name 填 **`COVERS`**（全大写），Bucket 选择 `trn-covers`，作用于 Production。
6. 保存后，在 Deployments 对最新 main 部署执行重新部署，让新绑定生效。
7. 打开 `https://tomatoricenoodles.pages.dev/admin/`，进入作品设置选择一张图片测试。

R2 bucket 本身不需要开启公开访问，也不用创建自定义域名。本项目通过 Pages Functions 的 `/media/covers/<uuid>.<ext>` 从绑定桶读取图片，图片 URL 保存在原数据库字段里。

如 Cloudflare 提示需要开通或绑定付款方式，按 Cloudflare Dashboard 的当前说明操作；不要把 API Token 或密码发给 ChatGPT 或写入 GitHub。

## 使用说明

- 图片支持 JPG/JPEG、PNG、WebP、GIF，文件最大 **5 MB**；出于安全考虑不接受 SVG 直接上传。
- 图片上传成功后，文章编辑器的封面地址会自动填好。草稿会继续遵循已有的自动保存；公开作品仍需手动点击「保存文章」。
- 系列/书籍上传完成后请点击管理弹窗的「保存」，才会把新封面地址与该作品关联。
- 删除或更换封面暂时**不会自动清理 R2 中旧图片文件**，避免误删被其他文章引用的图片。未来可以增加图库和清理功能。
- 已有 HTTPS 图片和 `/assets/graphics/...` 路径继续有效。中英文站共用同一存储桶，但各自作品资料依然独立。
- 如果按钮提示「图片存储尚未配置」，先确认 Production 绑定变量名完全为 `COVERS`，然后重新部署。
- 无需将桶内容设置公开；所有访问都经由受控的 Pages Function 路由。

## 相关源码

- `functions/api/admin/upload-cover.js`：管理员登录 + CSRF 验证，检查图片魔数与大小，上传 R2
- `functions/media/covers/[file].js`：向公开站点安全提供封面图片
- `assets/cover-upload.js` / `assets/cover-upload.css`：管理后台的图片选择、拖拽、预览、上传状态
