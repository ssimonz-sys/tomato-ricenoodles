# 系列管理（中英文共用一个后台）

## 最省事的升级办法

1. 等 Cloudflare Pages 将 GitHub 的 main 分支自动部署成功。
2. 打开 https://tomatoricenoodles.pages.dev/admin/ 并登录。
3. 在左侧切换到「系列书架」，点击「启用系列管理」。
4. 确认后，系统将为 trn-writings 新建一个 trn_series 数据表，自动导入原来的八个中英文专题系列。
5. 稍后刷新「系列书架」，会出现「＋ 新建系列」和每个系列的编辑、删除按钮。已有书、章、节以及文章正文不受影响。

此初始化由已登录作者的后台执行，需要有效的管理会话与 CSRF 验证。按钮只在系列数据库尚未启用时出现。它不会覆盖既有文章、书籍或系列。系列创建后会保存到 D1，Cloudflare Pages 自动部署时不会清空这些数据。

## 系列功能

- 新建：选择中文站或英文站，填写系列名、英文网址标识、简介、封面、颜色主题、分类、排序与公开状态。
- 编辑：可以改名字、简介、封面、分类、排序及公开状态。系列标识创建后固定，避免已经发布的书籍或文章引用失效。
- 删除：只有系列下不再关联书籍或文章时才允许删除。操作前会再次确认。
- 关联书籍：在系列旁点击「＋书」即可创建直属书籍；也可以编辑任意已有书籍的「所属系列」。
- 关联文章：编辑文章时，在「所属专题」输入框下面选择系列；同一篇文章可以属于多个系列。
- 中文和英文系列各自独立。草稿系列不会在公开专题页列出。

## 一键升级失败时的手工备选

Cloudflare Dashboard → D1 SQL Database → trn-writings → Console。
从 [migrations/2026-11-09-series.sql](https://github.com/ssimonz-sys/tomato-ricenoodles/blob/main/migrations/2026-11-09-series.sql) 复制三条 SQL，逐条 Execute：创建表、创建索引、导入已有八个系列。请勿将多条 SQL 及注释复制为同一行。

检查：运行 `SELECT language, slug, title FROM trn_series ORDER BY language, sort_order;`，应看到现有八个系列。该升级不会触及 posts、trn_books、trn_chapters、trn_section_links 数据。

不要在已有系列被编辑或删除后重新执行 INSERT 默认系列的种子 SQL，以免重新生成已经删除的旧系列。
