# 番茄米线后台使用说明

两个页面分工：

- **写作编辑**：https://tomatoricenoodles.pages.dev/admin/。独立大画布，专注撰写和编辑正文；原有的 Markdown、富文本、专注模式、明暗主题、草稿与公开发布仍然保留。
- **作品管理**：https://tomatoricenoodles.pages.dev/admin/manage/。单独管理中英文系列、书籍、章节、小节和文章。可以筛选语言、搜索全部文章、编辑系列、调整章节归属、删除空章与空书、删除文章。

## 推荐流程

1. 在「作品管理」新建系列，或编辑已有系列。
2. 进入系列，添加书，再为书添加章。
3. 在章中点击「＋ 写新节」，自动进入写作编辑页；首次保存时自动将正文关联到原章节。
4. 以后可以在书架中点击节的「写作」，或在「全部文章」里找到它，继续编辑。
5. 独立短篇、随笔、诗歌可以直接点击「＋ 新建文章」，不必创建书和章。
6. 已有文章可以通过「关联文章」或者文章列表中的「加入章节」移动到某个章节，不会清除文章正文。

两页共用 Cloudflare D1 的帖子及层级表，登录会话也是同一个。改变后台布局无需数据库迁移。
已有系列、书籍、章节、文章与草稿不会因为前端页面重组而改变。

## 其他说明

- 作品管理中的「删除文章」会永久删除正文，需要确认；移动文章到章节仅改变其目录关联。
- 「新建系列」若发现系列表未初始化，会提供一次性初始化流程。
- 如在写作编辑中已有未保存内容，离开页面会由浏览器提示。
- 修改网站的中文或英文公开主题，不需要在这两个后台页面操作。
