# 番茄米线：草稿自动保存、读者互动与作品分类

## 作品管理

访问 https://tomatoricenoodles.pages.dev/admin/manage/ 。

- 「系列与书籍」：中文或英文系列 → 书 → 章 → 节。
- 「文章与草稿」：选择中文站或英文站，进一步按政论与随笔、小说、诗歌、笔记与杂记分类，按全部作品 / 草稿 / 已发布筛选。
- 「评论审核」：审核匿名评论，批准、拒绝或删除，查看待审核数量。每篇文章的管理列表也会展示阅读、喜欢、已批准评论数。

## 启用读者互动（只需一次）

1. 等 GitHub 的最新 main 分支被 Cloudflare Pages 自动部署。
2. 登录 /admin/manage/ 。
3. 打开「评论审核」，点击「启用阅读量、点赞与评论」。
4. 系统将以已验证的管理员会话初始化四张新表与索引，无需在 Console 手动填写 SQL。
5. 如果你希望手动执行，可打开 [migrations/2026-11-10-engagement.sql](https://github.com/ssimonz-sys/tomato-ricenoodles/blob/main/migrations/2026-11-10-engagement.sql)，在 trn-writings 的 D1 Console 中把每个 SQL 语句分别 Execute，不粘贴开头注释。

新增数据表：
- trn_engagement_stats：每篇文章累计阅读量及点赞。
- trn_read_receipts：同一浏览器同一文章 24 小时内重复访问不新增阅读量。
- trn_likes：同一浏览器每篇文章最多点赞一次。
- trn_comments：匿名评论，初始 pending，仅审核通过 approved 的评论公开显示。

匿名评论无需注册或昵称，统一显示为「读者评论」。匿名留言长度要求为 2–1000 字，含蜜罐字段及每 IP 每小时最多五条的限制。后台可以批准、拒绝和删除评论；没有开放无需审核的匿名发布。

分享按钮优先调用浏览器原生分享，无原生分享时复制网址。分享功能即使未启用互动数据库也可使用。

## 草稿自动保存

- 新建或编辑私密草稿：输入结束约 3.5 秒后尝试将有效内容保存到 D1。如果还没有标题，先在当前浏览器留下恢复副本。
- 已发表文章的修改：保留本机恢复副本，必须使用「保存文章」提交。不会通过自动保存改变公开状态。
- 浏览器刷新后，如果恢复副本比云端新，写作页会询问是否恢复。
- 云端保存成功后会删除对应本机恢复副本。
- 新建章节小节首次保存成功后会自动关联到目标章节。

提醒：自动保存需要网络和有效管理员会话，提交状态以写作页顶部提示为准；网络异常时本机副本仍可能因浏览器清理而丢失。重要长文建议定期离线备份。

## 兼容性

- 沿用现有 trn-writings 的 posts 数据，迁移只新增互动相关表，不会删除文章或更改正文。
- 两种语言的公开网站与写作后台继续共用各自文章的统计。中文与英文作品仍然相互独立。
- 互动是公开读者行为数据，请勿用它作为精确的唯一自然人统计。
